# Beethoven for Claude Desktop and Claude Code

Beethoven runs Claude Code and is not an Anthropic product; "Claude" and "Claude Code" are Anthropic's marks, used here to say what it runs; "Open OnDemand" is the mark of its publisher.

The desktop edition of Beethoven: a local MCP server, packaged as a Claude Desktop extension and as a
Claude Code plugin, that reaches a student's Claude Code worker on their university's grid over their
own ssh sign-in. The cluster side is `OpenSpineConsortium/hpcworker`; the browser edition is
`OpenSpineConsortium/beethoven-extension`.
